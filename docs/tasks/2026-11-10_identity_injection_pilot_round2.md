## 0. 背景

负责人看过第一轮拼图，结论如下：

- P0 和 P1、P6 确实让脸变成了供体。025 上 P1 尤其清楚，胡子和皱纹都在。001 上 P1 在发际线附近发虚、有重影。
- 第一轮“清晰度比”是用**本人**干净版作分母，**指标设计有缺陷**：脸部纹理的多少因人而异，比如本人戴眼镜、有皱纹，供体皮肤光滑。所以换成供体后，即使画面清楚，这个比值也会偏低。这是负责人的设计问题，不是你的实现问题。
- 报告中“bank 分组/顺序会实质影响注意力读取”的解释不成立。注意力对 token 的排列顺序不敏感，同一组 token 换个顺序，结果应当相同。P1 和 P6 的差异，更可能来自第一轮第 1 节规定的**过渡上下文规则不同**：P1 在 w < 1 的上下文里按 w 做线性混合，P6 只在 w ≥ 0.5 时拼接。

本轮做三件事：

1. 事后修正清晰度指标；
2. 用对照实验核实 P1 和 P6 的差异来源；
3. 以 P1 为基础，找剂量，并试着解决发际线重影。

本轮仍是**探索性试点，不登记验收门槛**。第 4 节的候选标准在看结果之前就生效。

## 1. 事后修正清晰度指标（不重新生成）

新口径叫“清晰度 v2”：

- 用逐帧人脸检测框裁出脸，**缩放到 256 × 256** 再转灰度，计算拉普拉斯方差。这样可以消除脸在画面里大小不同带来的影响。
- 分母改成**供体自己的干净生成版**在同一窗口 W1 = [96, 144) 内的均值：
  - 001 的供体是 002，用 `chain_identity_drift/run_20261109/CRB100_002/clean_a`；
  - 025 的供体是 050，用 `.../CRB100_050/clean_a`。
- 同时报告以本人干净版为分母的比值（也按 256 × 256 口径），方便对照。

对第一轮的 16 条和本轮新生成的全部视频，都按 v2 口径计算。第一轮的候选判定按 v2 重新做一遍，结果单列，标注“**事后修正指标**”。第一轮报告里原来的数字和结论原样保留。

## 2. 改正 P1 / P6 的解释，并补对照

1. 在报告中删除“bank 分组/顺序会影响注意力读取”的说法，改成：“差异原因待本轮对照核实；最可能来自过渡上下文规则不同。”
2. 新增变体 **P1b**：做法与 P1 相同（脸框内 token 整块替换成对齐供体的 token，所有层），但过渡规则改成和 P6 一样：只在 w ≥ 0.5 的上下文里替换，w < 0.5 的上下文放回原对象，**不做任何线性混合**。
3. 报告 P1b 和 P6 窗口内对本人、对供体的 ArcFace 差值，并说明 P1b 和 P6 的 `raw_output_sha256` 是否相同。如果不同，再给出逐帧像素平均差的最大值。
4. 结论按以下三种之一写：
   - P1b 与 P6 两项 ArcFace 的差都 ≤ 0.01：差异来自过渡规则，解释得到证实；
   - 差值仍然 ≥ 0.05：说明另有原因，列出两者实现上的所有不同之处；
   - 其他情况：无法判断。

## 3. 新变体（每人各 1 条）

本节的新变体一律使用 P1b 的过渡规则（w ≥ 0.5 才替换，不做线性混合）。原因是第 3 步和第一轮都显示，线性混合会把脸抹平。

| 编号 | 做法 | 想回答的问题 |
|---|---|---|
| P1b | 见第 2 节（替换比例 p = 1.0，脸框外扩 25%） | 对照组，同时也是剂量曲线的 p = 1 端点 |
| D75 | 同 P1b，但脸框内随机选 75% 的 token 替换 | 身份是随替换比例逐渐变，还是过了阈值突然变？ |
| D90 | 同上，换 90% | 同上 |
| H50 | 同 P1b（p = 1.0），但脸框各边外扩 50%，把头发也框进去；这个大框要做成一张核对图 | 发际线的重影能不能消除？ |

- 随机抽取规则与第一轮 P4 相同：种子固定为 0，每层独立抽取，整个窗口内固定不变。
- 第一轮的 P4（随机换 50%、线性混合规则）可以作为参考数据点，但它的过渡规则不同，报告里要注明。
- 合计：4 个变体 × 2 人 = 8 条视频。clean 仍复用第 3 步的 `clean_a`，复用前先核对哈希。

## 4. 测量与候选标准（看结果前生效）

测量项目与第一轮相同，清晰度换成 v2：

- 窗口内对本人、对供体的 ArcFace；
- 清晰度 v2；
- 窗口外对本人的 ArcFace 变化；
- 有效人脸帧数。

**候选标准：** 两个人都要满足：
- 对供体的 ArcFace 上升 ≥ 0.15；
- 对本人的 ArcFace 下降 ≥ 0.30；
- 清晰度 v2（以供体干净版为分母）≥ 0.8；
- 窗口外对本人的 ArcFace 变化绝对值 ≤ 0.02。

**剂量曲线（只报告）：** 每人按 p = 0.5（P4，注明规则不同）、0.75、0.9、1.0（P1b）的顺序，列出对本人的下降量、对供体的上升量、清晰度 v2，并画成曲线。用一句话描述：身份是逐渐改变，还是在某两档之间突然改变。
