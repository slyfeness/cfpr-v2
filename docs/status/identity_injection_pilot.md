## 结论

没有候选变体。P0 在两人均有供体 ArcFace 上升（+0.282 / +0.642，均超过 +0.15），所以本生成器加评价器组合可以测出“朝指定供体移动”。但 P0 的清晰度比为 0.146 / 0.714，未达 0.8；其余方法也未同时满足四项条件。

候选条件：两人均需 donor rise >= 0.15、own drop >= 0.30、sharpness ratio >= 0.80、且 abs(outside own delta) <= 0.02。所有数值为 W1=[96,144)；窗口外为 [0,72) ∪ [168,240)。

## P1 与 P6 一致性检查

P1 与 P6 的窗口内 ArcFace 差（P1−P6）：001 own −.0021、donor −.0832；025 own +.0020、donor −.0695。own 读数非常接近，而 donor 读数存在约 .07–.08 差，故“token 集合相同即可结果相同”不成立：token 的 bank 分组/顺序会影响注意力读取。
